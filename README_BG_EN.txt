SUPPLIER FILE AUDIT — PUBLIC DEMO SITE

БЪЛГАРСКИ
1. Качете съдържанието на тази папка в корена на GitHub репозитори за GitHub Pages.
2. В Settings > Pages изберете Deploy from a branch, main, /(root).
3. След публикуване отворете адреса на сайта и натиснете „Изпробвай демото“.
4. Не качвайте клиентски файлове в публичното GitHub репозитори. Пакетът съдържа само синтетичните демонстрационни CSV файлове.
5. Сайтът няма форма за събиране на лични данни и няма плащания.
6. Преди публично промотиране е препоръчително реално тестване на различни CSV файлове и преглед на съвместимостта и сигурността.

ENGLISH
1. Upload the contents of this folder to the root of a GitHub repository for GitHub Pages.
2. Under Settings > Pages, select Deploy from a branch, main, /(root).
3. After deployment, open the site URL and click Try the free demo.
4. Do not publish real customer files in the GitHub repository. Included CSV data is synthetic.
5. No personal data collection form or payments are included.
6. Test CSV edge cases and review compatibility/security before wider public promotion.
